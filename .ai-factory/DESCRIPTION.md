# Описание проекта: Massnedra

## Обзор
Интерактивный лендинг о недрах (полезных ископаемых региона) с картой на базе
Яндекс.Карт API 2.1. Пользователь последовательно углубляется: области → районы →
участки (точки на карте) → карточка участка. Статический сайт без бэкенда:
все данные (границы регионов, центры районов, участки) генерируются скриптами
в предсобранные JSON/GeoJSON и отдаются как статика.

## Ключевые возможности
- Интерактивная карта (Яндекс.Карты) с границами регионов и точками участков
- Пошаговая навигация drill-down (регионы → районы → участки) со стеком истории («назад»)
- Списки и карточки участков, синхронизированные с картой
- Адаптивная вёрстка mobile-first с поддержкой legacy-браузеров (IE 11, Android 4.4, iOS 9)
- Деплой на GitHub Pages по подпути `/massnedra/`

## Технологический стек
- **Язык:** TypeScript ~6.0.2 (strict, без тестового фреймворка)
- **Сборщик:** Vite ^8.2.2 (web root = `src/`, вывод в `docs/`)
- **CSS:** нативный CSS + lightningcss, PostCSS (combine-media-query), browserslist-таргеты
- **Транспиляция:** @rollup/plugin-babel + @babel/preset-env (targets: ie 11, ios 9) + core-js 3 polyfills
- **Карта:** Яндекс.Карты API 2.1 (внешний скрипт, API-ключ в index.html)
- **Генерация ассетов:** sharp (изображения), svgo (SVG), ttf2woff/ttf2woff2 (шрифты)
- **Геоданные:** Python-скрипты (`scripts/build-plots-data.py`, `build-region-borders.py`) → JSON/GeoJSON
- **Хостинг:** GitHub Pages (ветка с `docs/` как web root)

## Архитектура
Подробные архитектурные guidelines см. в `.ai-factory/ARCHITECTURE.md`.
**Паттерн:** Слоистая архитектура (Layered Architecture), адаптированная под
статический фронтенд без фреймворка.

## Архитектурные заметки
- Модули `src/js/` разделены по ответственности: `main.ts` (точка входа/рендер),
  `navigation.ts` (конечный автомат навигации со стеком истории), `dom.ts`
  (ссылки на DOM), `types.ts` (типы), `data/` (данные участков/регионов),
  `map/` (обёртка Яндекс.Карт), `ui/` (рендер списков/карточек), `vendor/`
- Состояние навигации — явный тип `NavState`; переходы через единый
  `transition()`, история — массив `NavState[]`
- Данные не редактируются вручную в `src/`: источники в `scripts/*.json`,
  генерация в `public/geo/` и далее в бандл
- Никаких runtime-зависимостей — только devDependencies

## Нефункциональные требования
- **Логирование:** минимальное (`console.warn` в render), без новых логов
- **Обработка ошибок:** guard-условия, ранние возвраты; проверка типов на этапе сборки
- **Верификация:** `npm run build` (= assets → `tsc --noEmit` → `vite build`); ручная проверка сценариев в браузере
- **Безопасность:** API-ключ Яндекс.Карт публичный по умолчанию (client-side), реферы GitHub Pages
- **Деплой:** `npm run deploy` = build → commit `docs/` → push
