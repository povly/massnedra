# Базовые правила проекта

> Автоматически определённые соглашения из анализа кодовой базы. Редактируйте при необходимости.

## Соглашения об именовании

- Файлы (TS/JS): camelCase — `main.ts`, `navigation.ts`, `dom.ts`, `convert-images.js`
- Переменные и функции: camelCase — `openDistricts`, `goBack`, `transition`, `returnState`
- Типы/интерфейсы: PascalCase — `NavState`
- CSS-классы: kebab-case, в `src/css/*.css`
- Конфиг-скрипты: kebab-case — `build-plots-data.py`, `convert-fonts.js`

## Структура модулей

- `src/` — веб-корень Vite: `index.html`, `js/`, `css/`, `assets/`
- `src/js/` — модули по ответственности: `main.ts` (вход/рендер), `navigation.ts`
  (автомат навигации), `dom.ts` (DOM-ссылки), `types.ts` (типы), `data/`, `map/`, `ui/`, `vendor/`
- `public/` — статика без обработки (шрифты, favicon, geo, images)
- `scripts/` — генерация ассетов и геоданных (Node + Python)
- `docs/` — ТОЛЬКО собранный вывод (`vite build`), не редактировать вручную

## Обработка ошибок

- Guard-условия и ранние возвраты; без глубокой вложенности
- Типобезопасность проверяется на сборке: `tsc --noEmit` в `npm run build`
- Отсутствие runtime-зависимостей: ошибки DOM/карт обрабатываются локально в модуле

## Поток управления

- Предпочитайте плоский, читаемый поток управления вместо глубоко вложенных условных конструкций. Используйте guard-условия, ранние `return`/`continue`, небольшие именованные функции-помощники или явную логику классификации, когда они делают код понятнее. Обрабатывайте краевые случаи и нерелевантные ветки рано, чтобы основной путь оставался видимым.

## Логирование

- Минимальное: `console.warn` только для диагностики рендера; не добавлять новое логирование без явного запроса

## Верификация и сборка

- Проверка изменений: `npm run build` (assets → tsc --noEmit → vite build)
- Сценарная проверка UI — вручную в браузере (проект без тестового фреймворка)
- Коммит собранного `docs/` — только через `npm run deploy` или явный запрос пользователя

## Язык

- Пользовательский контент сайта, комментарии и артефакты — на русском; технические термины (API, map, state) — на английском
