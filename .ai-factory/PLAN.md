# Fix: Пошаговая история навигации («назад» не сбрасывает в начало)

- **Date:** 2026-09-05
- **Mode:** fast (no branch, work on `main`)
- **Scope:** `src/js/navigation.ts`, `src/js/main.ts`

## Original Request
Еще один моент где по точкам нажиамю туда сюда, и нажимаю назад в начало ставит! надо сделать так чтобы запоминал все и могли обратно идти к списку точек районы и прочее

- **Testing:** no — статический лендинг; верификация `npm run build` + ручная проверка сценария в браузере

## Диагноз (текущее поведение)
`navigation.ts` хранит ОДИН слот `returnState` (строка 30), который `openObject()` перезаписывает
текущим состоянием. Сценарий бага: клик по точке A на карте → `returnState = {regions}`; клик по
точке B → `returnState = {object}` (текущий уровень уже `'object'`) → «назад» №1 применяет
`{object}` (визуально ничего не меняется), «назад» №2 — падение в `{regions}` = «в начало».
История также не помнит, какой участок был открыт, поэтому возврат A ↔ B невозможен.

Решение: структурный стек истории (drill-down) — списки (regions→districts→plots) пишутся в
историю, а повторный выбор точки на уровне `'object'` перезаписывает только `plotName`
(точки не наслаиваются); в состояние объекта добавляется `plotName` для восстановления карточки.
«Назад»: объект → список точек → районы → области → (в корне бездействует).

## Notes / Risks
- Стек растёт только от forward-переходов; дедупликация одинаковых соседних состояний не даёт
  истории разрастаться от повторных кликов в ту же точку.
- Балун на карте при возврате «назад» к участку не переоткрывается — минимальное изменение,
  текущее поведение не regressирует (балун открывается только при явном клике/выборе).
- Кнопка «назад» на корневом экране остаётся видимой и бездействует — как сейчас; скрытие по
  уровню — вне скоупа.
- Зависимости между задачами: T2 зависит от T1 (новая сигнатура + getter).
