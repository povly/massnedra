# Архив: датасет участков v1 (до перехода на МАН)

> Заархивирован 2026-09-06 при переходе на новый датасет
> «Объекты для размещения на сайте МАН». Здесь всё, что нужно,
> чтобы восстановить или пересобрать прежнюю версию карты.

## Происхождение

Старый пайплайн (`build-plots-data.py` до переработки) собирал
`src/js/data/plots.ts` из ДВУХ источников:

1. **xlsx с полигонами** (ГСК-2011, DMS) — приходил аргументом командной
   строки из Telegram-загрузок, **в репо не хранился**. Имена участков —
   «№NN. Имя» (например «№55. Дямкундя», «№80. Гольцовый»).
2. **`plots-site.json`** — карточки, спарсенные с
   massnedra.com/investicionnye-proekty (заголовок, регион, описание с
   площадью/районом/ископаемыми, url). Сопоставление с xlsx — через
   substring-матч нормализованных имён + словарь ALIASES
   (дергарсы→дергасы, пластунский→пластонский, колонковый→колонковский).

## Файлы

| Файл | Что это |
|------|---------|
| `plots-site.json` | карточки со старого сайта (датасет №NN, вкл. Амурскую область) |
| `district-centers.json` | центры районов — фолбэк-точки для участков без полигона |
| `plots-v1.ts.txt` | снапшот сгенерированного `src/js/data/plots.ts` на момент архивации |

## Как использовать

- Снапшот `plots-v1.ts.txt` — переименовать в `plots.ts` и положить в
  `src/js/data/` (совместим с `PlotArea`, включал поле `point` с
  приблизительными точками).
- Для полной регенерации v1 нужен старый xlsx (не хранился) — только из
  внешнего источника; скрипт той эпохи лежит в git-истории
  (до коммита «feat(data): single-source MAN plot generator»).
