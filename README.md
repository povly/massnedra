# Massnedra

> Интерактивная карта недр Дальневосточного региона: области → районы → участки недр.

Лендинг об инвестиционных проектах в сфере недропользования. Интерактивная карта
на Яндекс.Картах позволяет последовательно углубляться от регионов к районам и
конкретным участкам: списки, карточки участков, полигоны и точки на карте.
Статический сайт без бэкенда — все данные предсобраны скриптами.

## Быстрый старт

```bash
npm install     # установка зависимостей (только devDependencies)
npm run dev     # dev-сервер на http://localhost:5173
```

Требуется Node.js и браузер с доступом к api-maps.yandex.ru.

## Ключевые возможности

- **Карта Яндекс.Карт** — контуры регионов, точки и полигоны участков
- **Пошаговая навигация** — области → районы → участки со стеком истории (кнопка «назад» не сбрасывает прогресс)
- **Карточки участков** — данные из massnedra.com, синхронизированы с картой
- **Поддержка legacy-браузеров** — IE 11, Android 4.4, iOS 9 (babel + core-js + lightningcss)
- **Деплой на GitHub Pages** — по подпути `/massnedra/`

## Пример структуры данных

```typescript
// src/js/data/plots.ts (генерируется скриптом)
export const plots: PlotArea[] = [
  {
    name: 'Колонковский',
    region: 'Хабаровский край',
    location: 'Район имени Лазо',
    areaKm2: 12.4,
    minerals: ['олово', 'золото'],
    point: [49.47, 137.21],    // [lat, lon] точка для Яндекс.Карт
    polygon: [[49.4, 137.1], /* ...контур участка */],
    // ...карточка участка
  },
];
```
