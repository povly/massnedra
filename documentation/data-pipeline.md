# Данные и ассеты

Ни данные участков, ни контуры регионов не редактируются вручную — всё
генерируется скриптами из первоисточников.

## Источник участков (датасет МАН)

| Артефакт | Скрипт | Источник | Вывод |
|----------|--------|----------|-------|
| Участки (карточки + полигоны + метки) | `scripts/build-plots-data.py` | `scripts/source/Объекты_для_размещения_на_сайте_МАН.xlsx` | `src/js/data/plots.ts` |

Xlsx — единственный источник: карточные поля (название, регион, район, площадь,
ископаемые) и координаты лежат в одном файле. Колонки: **Участок / Регион /
Расположение / Площадь, км.кв. / Полезные ископаемые / Координаты
(ГСК-2011, DMS построчно — вершины полигона)**.

Вспомогательный файл: `public/geo/regions.json` — контуры регионов для карты
(см. ниже).

## Регенерация участков

```bash
uv run --with openpyxl python3 scripts/build-plots-data.py \
    scripts/source/Объекты_для_размещения_на_сайте_МАН.xlsx
```

Что делает скрипт:

1. Читает xlsx, парсит DMS-координаты (ГСК-2011 → десятичные градусы [lat, lon])
2. Метка участка (`point`) = **центроид полигона** — метка всегда в центре территории
3. Участки с полигоном < 3 вершин пропускаются с предупреждением
4. Сортировка: регион, затем название; запись типизированного `plots.ts`

## Архив старого датасета

Прежний датасет (карточки с massnedra.com «№NN. Имя» + центры районов) сложен
в `scripts/archive/plots-v1/` — см. README внутри. Старый xlsx в репо не
хранился; генератор той эпохи доступен в git-истории.

## Регенерация контуров регионов

```bash
python3 scripts/build-region-borders.py <исходный.geojson>
```

Скрипт вырезает из полного GeoJSON нужные субъекты ДФО (Хабаровский и Приморский
края, Магаданская, Иркутская, Амурская области, Республика Бурятия) и сохраняет
их контуры в формате Яндекс.Карт (MultiPolygon, `[lat, lon]`).

## Ассеты (изображения, SVG, шрифты)

```bash
npm run assets    # всё сразу
```

| Скрипт | Инструмент | Что делает |
|--------|-----------|------------|
| `scripts/convert-images.js` | sharp | Оптимизация изображений |
| `scripts/convert-svgs.js` | svgo | Минификация SVG |
| `scripts/convert-fonts.js` | ttf2woff / ttf2woff2 | Конвертация шрифтов |

Результат кладётся в `public/` (fonts, images) — Vite копирует их в сборку без обработки.

## Правила

- ❌ Не редактируйте `src/js/data/plots.ts` и `public/geo/regions.json` руками —
  изменения будут перезаписаны следующей генерацией
- ❌ Не редактируйте `docs/` — это вывод `vite build`
- ✅ Новые данные участков: обновите `scripts/source/*.xlsx` и перегенерируйте
- ✅ Новый регион: добавьте его в `NEEDED` в `build-region-borders.py` и перегенерируйте
