# Быстрый старт

## Предварительные требования

- **Node.js** — для npm-скриптов, Vite и TypeScript
- **uv** (для регенерации данных участков) — https://docs.astral.sh/uv/
- **Браузер с интернетом** — карта загружается с `api-maps.yandex.ru`

## Установка и запуск

```bash
npm install     # зависимости (только devDependencies, runtime-зависимостей нет)
npm run dev     # dev-сервер: http://localhost:5173
```

Проверка: откройте http://localhost:5173 — должна отрисоваться карта с контурами
регионов ДФО и панель со списком областей.

## npm-скрипты

| Скрипт | Что делает |
|--------|------------|
| `npm run dev` | Vite dev-сервер (порт 5173) |
| `npm run build` | Полная сборка: ассеты → `tsc --noEmit` → `vite build` (вывод в `docs/`) |
| `npm run preview` | Локальный предпросмотр собранного сайта |
| `npm run assets` | Регенерация всех ассетов (изображения + SVG + шрифты) |
| `npm run deploy` | Сборка → коммит `docs/` → push (публикация на GitHub Pages) |

Ассеты по отдельности: `assets:images` (sharp), `assets:svg` (svgo), `assets:fonts` (ttf2woff/woff2).

## Верификация изменений

Проект не имеет тестового фреймворка. Проверка изменений:

```bash
npm run build
```

Сборка включает `tsc --noEmit` — типобезопасность проверяется здесь. Для
сценарной проверки (навигация, карта) — ручной прогон в браузере.

## Частые проблемы

- **Карта не загружается** — проверьте доступ к `api-maps.yandex.ru`; API-ключ
  подключается в `src/index.html`
- **Изменились данные участков, но сайт старый** — данные генерируются скриптами,
  см. [Данные и ассеты](data-pipeline.md)
- **Ошибка типов при сборке** — `npm run build` показывает точное место; правьте TS, не собранный вывод
